Evangadi course 'Database Administration' has 3 phases.
Evangadi Database Administration Phase 1: Introduction to SQL Server and Databases
Evangadi Database Administration Phase 1 details: In this phase, you'll get introduced to SQL Server, learning about its structure and role in managing data. You'll also explore the fundamentals of relational databases and understand how they work through the Relational Database Management System (RDBMS) framework. Along the way, you'll perform basic administrative tasks, set up databases, and get hands-on experience with SQL Server. By the end of this phase, you'll have a solid foundation to manage and configure a SQL Server environment.
Evangadi Database Administration Phase 1 covers weeks including: Introduction to SQL Server and Databases week, Introduction to SQL Commands week, Mastering SQL Clauses and operators week, Advanced Techniques for SQL Data Manipulation and Management week.
Evangadi Database Administration Phase 2: Mastering SQL Server Reporting and Integration Services (SSRS & SSIS)
Evangadi Database Administration Phase 2 details: In this phase, you'll master SQL Server Reporting Services (SSRS) and SQL Server Integration Services (SSIS). In SSRS, you'll learn to create and enhance reports, using advanced features like subreports, drilldown, drillthrough, dynamic sorting, and report deployment. In SSIS, you'll focus on automating data flows with transformations, such as moving data between flat files, Excel, and OLDB, while optimizing performance and managing workflows through control flow tasks. By the end, you'll be proficient in building reports and automating data processes with SSRS and SSIS.
Evangadi Database Administration Phase 2 covers weeks including: SSRS Introduction and Report Creation, Advanced Reporting Techniques in SSRS, Introduction to SQL Server Integration Services (SSIS), Advanced Data Flow and Control Flow in SSIS.
Evangadi Database Administration Phase 3: Mastering SQL Server Database Administration
Evangadi Database Administration Phase 3 details: In this phase, you'll learn to manage SQL Server instances, perform backups and restores, automate tasks, and configure security. You'll also explore high availability, disaster recovery, and performance tuning using SQL Server Management Studio (SSMS).
Evangadi Database Administration Phase 3 covers weeks including: SQL Server Environment Setup and Backup Configuration, Automation & Security, Database Migration and High Availability/Disaster Recovery (HA/DR), Mastering Performance Tuning and Monitoring in SQL Server.
